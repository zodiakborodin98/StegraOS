## Separate Beta1 image experiment

A local4.626GB7z package contains a24GiB ordinary writable ext4 root, split as
Hekate Flash Linux l4t.00–06. FAT contains Hekate/boot/install files; Linux uses
the ext4 partition. This is not a whole-card raw image. About25GiB FAT plus the
remaining Linux space fits the tested64GB card; the old40GiB recommendation
was oversized. A >4GiB7z cannot be stored as one FAT32 file: extract from PC.

Archive integrity, exact chunk concatenation, manifests, e2fsck and offline
resize24→30GiB passed. The first hardware boot did not reach visible Steam.
The separate v4 boot update is installed, but no successful v4 boot is reported.
**The full Beta1 image is not hardware qualified or distributed by this repo.**
The original local image does not contain the later OLED/ZRAM changes; a
future coherent rebuild must integrate them rather than assuming a boot-only
update also changes rootfs. Developer leftovers and binary-redistribution
terms still need review. Do not delete apparently duplicated Steam/runtime
trees blindly: launcher binds and lowmem integration may depend on them.

## Compatibility and recovery

Normal launch policy checks payload integrity plus a usable session/runtime
contract; strict additionally checks exact experimental environment hashes.
This avoids rejecting ordinary ARM Runtime updates solely for changed hashes,
without accepting partial/inconsistent updates or arbitrary hybrid Wine/FEX.
The tools are selectable per game, with separate per-AppID prefixes; this is
not universal game compatibility. HL2DM uses DXVK/Vulkan, not WineD3D rendering.

The Steam service keeps its historical name:
```sh
sudo systemctl restart steam-cpu-session.service
```
Hold Capture3s is equivalent session rescue, not a kernel reboot. Software
poweroff/reboot remains unreliable on the legacy installation. Global hangs,
some EGLStream startup/teardown faults, Windows panel/lifecycle and FEX lowmem
return-to-Steam remain open. No new hardware test accompanies this publication.
