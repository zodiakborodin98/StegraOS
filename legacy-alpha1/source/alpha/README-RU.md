# Switchdeck SteamOS — Alpha 1

Это первая экспериментальная сборка SteamOS из официального образа Steam Frame
для Nintendo Switch Lite. Полная загрузка этой альфы, Steam, Wi-Fi, звук и
завершение работы пока **не проверены на консоли**. Ранее на твоём Lite успешно
прошли тест экрана и вычислений GPU в Boot0 r6; это была другая, диагностическая
сборка с NVIDIA 32.3.1. Здесь используется согласованный комплект NVIDIA 32.7.4.

## Установка

1. Распакуй архив целиком на ПК. На карте должен быть рабочий Hekate, с которого
   ты уже запускал r6. Файловая система загрузочного раздела — FAT32.
2. Скопируй **содержимое** папки `sd-card` в корень карты. В корне должны оказаться
   папки `bootloader` и `switchroot`, а не ещё одна папка `sd-card`.
3. Проверь, что существует файл:
   `switchroot/switchdeck-alpha/rootfs.squashfs`.
4. После копирования оставь на FAT32 **не меньше 4 ГБ свободного места**.
   При первом запуске создаётся `userdata.ext4` размером 3,75 ГиБ для настроек,
   обновляемых данных и небольших игр. Базовая система и предустановленный клиент
   находятся в отдельном сжатом образе.
5. Безопасно извлеки карту, вставь в Switch и подключи зарядку.
6. Hekate → **More configs** → **Switchdeck SteamOS Alpha 1**.

Переразметка карты не нужна. Установочный комплект не содержит `hekate_ipl.ini`
и `switch.cal`, не заменяет их и не удаляет r6. Запись eMMC отключена в новой
загрузочной записи. Разгоны к настройкам Switchroot не добавлены.

На каждом запуске проверяется SHA-256 файла системы. Первый запуск дополнительно
записывает почти 4 ГБ данных: на медленной карте это может занять несколько минут.
Сообщения загрузчика инициализируют лог в `switchdeck-logs`.

## Wi-Fi без клавиатуры

До первого запуска создай в `switchroot/switchdeck-alpha` файл `wifi.txt` в UTF-8:

```text
Название твоей сети
Пароль твоей сети
```

Ровно две строки, без кавычек и подписей. Поддерживается WPA/WPA2 PSK; для открытой
сети достаточно первой строки. Конфигурация импортируется NetworkManager.
**После успешного подключения удали `wifi.txt` с карты:** он содержит пароль
открытым текстом. В диагностический экспорт этот файл не включается.

Другой вариант — подключить USB-клавиатуру и выбрать `Wi-Fi setup` в меню альфы.
Вход в Steam требует интернета. Возможность авторизации ещё предстоит проверить.

## Интерфейс и управление

Настроен автоматический вход в X11/Openbox и запуск Steam Big Picture.
Если Steam завершится, появится меню: повторный запуск, настройка Wi-Fi,
терминал, экспорт диагностики, перезагрузка и выключение.

Используется раскладка мыши Switchroot: левый стик перемещает указатель,
ZR — левый клик, ZL — правый. **Capture** переключает эту раскладку; в Steam/игре
её может потребоваться отключить, чтобы избежать двойных нажатий.
С USB-клавиатуры **Win+Space** открывает меню, **Win+Enter** — терминал.

Для установки собственного пароля в терминале: `sudo passwd steamos`.
SSH в этой альфе отключён. Короткое нажатие POWER настроено на штатное выключение.
Сон/пробуждение пока не проверены; для первых тестов пользуйся выключением.

## Что внутри

- Система SteamOS 0.3.0 из официального Frame recovery от 22.09.2026.
- Ядро и загрузочный стек Switchroot 4.9.140; сохранена проверенная ветка панели
  `0F40` для твоего Lite.
- NVIDIA 32.7.4, включая совместимые назначения прошивок из `nvidia-bsp-32-7`.
- Xorg 1.20.13 с соответствующим ABI драйвера, Openbox и SDDM.
- Закреплённый совместимый снимок Steam ARM64 по проекту SildurFX/Switchdeck.
- Box64 для Tegra X1, Proton 11.0-1 ARMv8.0 FEX, DXVK-Sarek 1.13.0 и VKD3D 2.3.1.
- Компоненты Switchroot для контроллеров, звука и Wi-Fi/Bluetooth.

Gamescope не используется для основной сессии. Службы VR-шлема, обновления
прошивки Frame и штатное обновление его системы отключены. Приватные настройки
репозиториев Frame исключены. Автообновление закреплённого Steam отключено,
чтобы оно не заменило клиент на несовместимую сборку.

Наличие Proton/Box64 не гарантирует запуск конкретных игр. Это альфа для проверки
полной загрузки, интерфейса и небольших игр; 3,75 ГиБ свободного слоя недостаточно
для крупных установок. Подключение отдельной библиотеки требует следующего этапа.

## Если не загрузилось

Пришли фотографию последнего экрана и новые файлы из `switchdeck-logs`:
`alpha1-N-init.log` и, если он появился, `alpha1-N-system.log`.
Системный лог автоматически обновляется примерно раз в минуту после запуска
systemd. Не присылай `wifi.txt`, `switch.cal` и весь профиль Steam.

`INIT_COMPLETE` означает передачу управления системе, а не успешный запуск Steam.
Если создание данных прервалось и загрузчик сообщает про `userdata.ext4.new`,
удали на ПК **только этот незавершённый файл** и повтори запуск. Не удаляй
`userdata.ext4`: в нём находятся сохранённые данные.

Для отката выбери прежнюю запись Hekate/r6. Удаление папки `switchdeck-alpha`
удалит и данные этой альфы; для простого отката удалять её не требуется.

## Исходники и воспроизведение

Набор исходников содержит закреплённые URL/SHA-256, сборочные скрипты и отчёты.
Базовый Frame recovery и пакеты скачиваются из первоисточников. Выполнение
maintainer-скриптов Debian и установка пакетов в систему сборочного ПК не нужны.
Для промежуточных образов используй отдельный временный каталог с ≥25 ГБ места,
а не каталог, который автоматически синхронизируется во время записи.

Основа совместимости клиента: https://github.com/SildurFX/Switchdeck,
коммит `be0578fbf00c5a14a988a830f914f2c34cdaa1a1`. Адаптированный лаунчер
распространяется по GPL-3.0-only, лицензия включена в образ.
